## Contribution Guidelines

### When Adding New Documentation

1. Update this index file
2. Follow markdown best practices
3. Include table of contents for docs > 5KB
4. Add to appropriate reading path above
5. Update dependencies diagram

### Documentation Standards

- **Headings**: Use ATX style (`#` not underlines)
- **Code Blocks**: Always specify language (```typescript)
- **Links**: Use relative links between docs
- **Examples**: Provide working code examples
- **Updates**: Add date to changelog when updating

### Keeping Documentation Current

- Update with code changes (not separately)
- Review quarterly for accuracy
- Archive outdated sections
- Maintain consistent terminology
